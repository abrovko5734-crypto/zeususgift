# Zeusgift (виртуальные искры, без реальных денег)

Рулетка, Мины, Краш, Апгрейдер + заработок искр игрой «Лови молнии» + админка только для Telegram ID 7128871752.

## Запуск
1. GitHub: новый репозиторий, загрузи все файлы. Папка `api/` — через "Add file → Create new file", имя вводи с папкой, например `api/auth.js`, и вставь содержимое (на телефоне zip GitHub не распаковывает).
2. vercel.com → Add New → Project → выбери репозиторий → Deploy.
3. Vercel → Settings → Environment Variables:
   - `BOT_TOKEN` — токен бота из @BotFather (обязательно, иначе админка не откроется)
   - `ADMIN_ID` — 7128871752 (по умолчанию уже он)
   - `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` — бесплатная база upstash.com (нужна, чтобы сохранять настройки из админки; без неё игра работает на настройках по умолчанию)
   После добавления переменных сделай Redeploy.
4. @BotFather: `/newbot` → имя Zeusgift. Затем `/newapp` (или Menu Button) → URL твоего сайта на Vercel.

## Upstash обязателен для: рейтинга, сохранения прогресса на сервере, списка игроков и банов в админке.

## Безопасность
Админ определяется сервером по подписи Telegram (initData + BOT_TOKEN), а не по тому, что напишет клиент.
Результаты игр считаются в браузере, поэтому подходят только для виртуальных искр без вывода. Сервер хранит баланс, баны и рейтинг, но не пересчитывает ставки.
