Политика конфиденциальности ZeusGift

Дата обновления: 19 ноября 2026 г.

ZeusGift — развлекательная мини-игра с виртуальными очками. Очки не являются деньгами, не имеют денежной стоимости, не продаются и не обмениваются на деньги, товары или услуги. В приложении нет пополнений и выводов средств.

Какие данные используются

При запуске через Telegram приложение получает от Telegram технические данные профиля: Telegram ID, имя и публичный username (если он указан). Telegram ID используется для сохранения игрового баланса, защиты аккаунта и проверки доступа администратора.

Игровые данные

На сервере сохраняются баланс виртуальных очков, время получения ежедневного подарка, статус блокировки и история игровых раундов. Данные хранятся в базе Supabase, подключённой владельцем приложения.

Для чего используются данные

  • для работы игрового профиля и сохранения прогресса;
  • для выдачи ежедневного виртуального подарка;
  • для предотвращения злоупотреблений и применения блокировок;
  • для работы закрытой панели администратора.

Передача и безопасность

Приложение не запрашивает пароли Telegram, платёжные реквизиты или документы. Данные передаются серверу по HTTPS. Секретные ключи хранятся в переменных окружения на стороне сервера и не должны публиковаться в GitHub.

Удаление данных и связь

По запросу владельцу приложения можно попросить удалить игровой профиль. Контакт владельца: Telegram @Keldisqq.

Важно

Это развлекательный проект с виртуальными очками. Не используйте его для приёма платежей, ставок на деньги или обещания денежных призов.
